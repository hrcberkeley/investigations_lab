📚 How to Use EmbedScape

🎯 What is EmbedScape?

EmbedScape is a privacy-first embedding visualization tool that helps you explore your data semantically. All processing happens locally in your browser - your data never leaves your computer!

Key Features:

  • 🔍 Text ↔ Image semantic search (CLIP multimodal)
  • 📊 Interactive 2D visualization of semantic relationships
  • 🏷️ Manual tagging and filtering system
  • 🎥 Video processing with frame extraction
  • 💾 Save/load sessions to avoid reprocessing

1️⃣ Load Your Data

You have two ways to get data into EmbedScape:

📄 CSV Upload: Upload a CSV file with text and/or media URLs. Each row becomes a point in the visualization.

  • Text column: Text content to embed (optional)
  • Label column: Display name for each item (optional)
  • Link column: Clickable URLs (optional)
  • Image URL column: Links to images (optional)
  • Video URL column: Links to videos (MP4/WebM, optional)

📸 Direct Media Upload: Upload images and videos directly from your device.

  • Supported: JPG, PNG, GIF, WebP (images) • MP4, WebM (videos)
  • Drag & drop or click to browse
  • Multiple files allowed
  • Automatically configures for multimodal processing

2️⃣ Configure & Process

Choose your embedding settings:

  • Unified Multimodal (CLIP ViT-B/32): Text, images, and video frames are all projected into the same 512-dimensional CLIP embedding space, enabling cross-modal similarity search.
  • Hardware requirements: Uses WebGPU (q8 quantized) when available for GPU-accelerated inference; automatically falls back to CPU (WebAssembly) on unsupported browsers. Your data never leaves your device.
  • Batch size: Higher = faster, lower = less memory usage
  • Clusters: Number of k-means clusters for visualization

⚙️ Processing Pipeline:

  1. Generate embeddings from your data
  2. Cluster using k-means algorithm
  3. Reduce to 2D with UMAP for visualization
  4. Create interactive scatter plot

3️⃣ Semantic Search

🔤 Text Search: Enter any text query to find semantically similar items.

🖼️ Image Search: (Multimodal only) Upload an image to find similar text/images/videos.

💡 Pro Tips:
  • Click on search results to zoom and highlight that node
  • Adjust the similarity threshold (0.70 default) to control match strictness
  • Use descriptive queries: "a red sports car" vs "car"
  • For image search, try photos of objects, scenes, or concepts

🏷️ Manual Tagging System

Organize your data with custom tags:

  • Selection modes:
    • Off - Click to view details
    • Single select - Click to select one node
    • Multi-select - Ctrl/Cmd + click for multiple nodes
  • Add tags: Type tag name → click "+ Add Tag"
  • Remove tags: Type tag name → click "- Remove Tag"
  • Color modes: Switch between cluster colors and tag colors
  • Filter by tags: Select tags to show only those items
  • Persistence: Tags are saved with session files

🎥 Video Processing Details

Videos are processed by extracting frames and pooling their embeddings:

  • Frames per second (FPS): How many frames to extract (0.5-5 fps recommended)
  • Max frames: Upper limit per video (prevents timeouts)
  • Processing time: ~20-60 seconds per video depending on length
  • CORS requirements: Both image and video URLs must allow cross-origin access — CORS-blocked media is skipped (no proxy is used)
  • Embedding method: Mean pooling of CLIP vision embeddings across all extracted frames

📊 Interactive Visualization

  • 🖱️ Pan: Click and drag to move around the visualization
  • 🔍 Zoom: Scroll or pinch to zoom in/out
  • 👆 Click nodes: View detailed information in modal popup
  • 🎨 Colors: Different colors represent different clusters or tags
  • ✨ Highlighting: Search results glow gold, selected items glow cyan
  • 🏷️ Tooltips: Hover over nodes to see labels and tags

💾 Save & Load Sessions

Why save sessions? Embedding generation can be time-consuming. Save your work to continue later!

  • What's saved: Embeddings, coordinates, clusters, tags, and configuration
  • File size: Typically 1-10MB for CSV-based sessions; sessions with uploaded local images/videos will be larger (base64 data is embedded)
  • Benefits: Instant loading, no reprocessing needed
  • Portability: Share .json files with others — CSV-based sessions contain no original text data, only embeddings

🔧 Technical Details

Models & Libraries:

  • Embeddings: CLIP ViT-B/32 via CLIPTextModelWithProjection + CLIPVisionModelWithProjection (512 dimensions, shared space)
  • Runtime: transformers.js 3.x · WebGPU · q8 quantized · browser-cached after first load
  • Clustering: k-means algorithm
  • Dimensionality reduction: UMAP (n_neighbors=15, min_dist=0.1)
  • Visualization: deck.gl with WebGL acceleration
  • Processing: Web Workers (browser-based, no server required)
🔒 Privacy Notice: All processing happens locally in your browser using Web Workers. Your data, files, and content never leave your computer or contact any external servers (except for loading models from Hugging Face CDN, which is cached locally after first use).
💡 Getting Started: Try uploading a small CSV (10-50 rows) first to understand the workflow, then scale up to larger datasets. The interface is designed to guide you through each step!
