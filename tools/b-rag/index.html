About B-RAG

B-RAG is an experimental, in-browser RAG (Retrieval-Augmented Generation) tool that operates entirely on your device. No data is sent to any server.

How to use:

  1. Upload Documents: Select PDF, DOCX, TXT, or HTML files.
  2. Build Index: The app chunks your files and computes embeddings locally.
  3. Ask Questions: Type your query. The app retrieves relevant chunks and uses the browser's local language model to answer.

Note: This tool requires a browser with the Prompt API enabled (e.g., Chrome Canary with flags) or a polyfill.
