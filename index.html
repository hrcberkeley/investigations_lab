The kit

Six stages of an investigation, with a method and tools for each.

The worksheets teach the method. The tools speed it up. The browser tools work on your own device, so nothing you load into them goes to a third party.

    How the tools are built

    Local processing

    Where possible, everything runs in your browser. This matters for sensitive material, unreliable connections and contexts where surveillance is a concern.

    Clear interfaces

    Graphical interfaces with guidance on what each feature does, so you don't have to know how to program.

    Little or no installation

    Open the tool in a browser, or install it in a single step. No dependencies or environments to manage.

    These tools are prototypes. They work, but treat them as demonstrations of what current technology makes possible, and check their results.
