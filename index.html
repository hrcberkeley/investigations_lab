Six stages of an investigation, with a method and tools for each.

Each stage brings together the worksheets we use to teach the method in the Lab and the tools we've built along the way to make the work a little easier.

  1. i.

    Local processing

    Where possible, the tools run entirely in your browser, so whatever you load into them stays on your own device. This matters for sensitive material, unreliable connections and contexts where surveillance is a concern.

  2. ii.

    Clear interfaces

    Graphical interfaces with guidance on what each feature does, so you don't have to know how to program.

  3. iii.

    Little or no installation

    Most tools open straight in the browser, and the rest install in a single step, so nobody has to manage dependencies or programming environments to use them.

The tools are prototypes. They work, but treat them as demonstrations of what current technology makes possible, and check their results.
