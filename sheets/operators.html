Advanced Search Operators Quick Reference

This document provides an overview of advanced search engine operators for Google and Bing. Use these operators to refine your search results and find more precise information. Given tech’s capricious nature, they may stop working at any point.

1. Google Operators

1.1 Quoted Searches

  • Operator: "" (quotation marks)

  • Usage: Place a term or phrase in quotes.

  • Example: "artificial intelligence"

  • Effect: Returns results containing the exact phrase within quotes.

1.2 Exclusion

  • Operator: -

  • Usage: Prepend a minus sign to terms you want to exclude.

  • Example: machine learning -deep

  • Effect: Returns pages mentioning “machine learning” but not “deep.”

1.3 OR Searches

  • Operator: OR

  • Usage: Place OR between terms.

  • Example: robots OR automation

  • Effect: Returns results containing either "robots" or "automation" (or both).

1.4 Site Search

  • Operator: site:

  • Usage: site:domain

  • Example: site:wikipedia.org "quantum mechanics"

  • Effect: Returns results from a specific domain.

1.5 File Type Search

  • Operator: filetype:

  • Usage: search terms filetype:pdf

  • Example: "marketing plan" filetype:pdf

  • Effect: Returns documents of a certain file type (e.g., PDF).

1.6 In Title, URL, or Text

  • Operators: intitle:, inurl:, intext:

  • Usage: intitle:term, inurl:term, intext:term

  • Examples:

    • intitle:statistics

    • inurl:gallery

    • intext:"climate change"

  • Effect: Limits results to pages with the specified term in the title, URL, or body text.

1.7 Numeric Ranges

  • Operator: ..

  • Usage: term number..number

  • Example: smartphone 2019..2021

  • Effect: Finds results mentioning smartphone and any number in the specified range (e.g., years 2019, 2020, 2021).

1.8 Definitions

  • Operator: define:

  • Usage: define:term

  • Example: define:metamorphosis

  • Effect: Provides a definition or summary of the term (though often you can just type “define metamorphosis” without the colon).

1.10 Proximity Search

  • Operator: AROUND(X)

  • Usage: term1 AROUND(X) term2

  • Example: "artificial intelligence" AROUND(5) ethics

  • Effect: Returns results where the two terms appear within X words of each other. The number in parentheses specifies the maximum word distance between the search terms.

2. Bing Operators

Bing shares many of the same operators with Google (such as quotation marks, minus sign, and OR). Some Bing-specific nuances are listed below.

2.1 site:

  • Usage: site:microsoft.com edge browser

  • Effect: Searches only within microsoft.com.

2.2 filetype:

  • Usage: bing ads filetype:ppt

  • Effect: Searches for files of a specific type (e.g., PPT).

2.3 contains:

  • Usage: example.com contains:pdf

  • Effect: Returns pages on example.com that link to PDF files.

2.4 language: (or lang:)

  • Usage: language:en keywords

  • Effect: Limits results to a specific language.

2.5 ip:

  • Usage: ip:192.168.1.1

  • Effect: Shows websites hosted at the specified IP address.

3. General Tips

  1. Combine operators to refine results (e.g., site:edu filetype:pdf "data science" -deep).

  2. Use parentheses to group search terms when combining operators (e.g., (AI OR "machine learning") intitle:research).

  3. Remember that advanced operators can change over time, and some operators may be deprecated or behave differently across Google and Bing.
